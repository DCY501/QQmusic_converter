## 更新内容

- **任务恢复与失败重试**：自动保存任务列表和设置；重新打开后检查源文件与输出状态，支持继续处理、重试失败和重新处理选中项。
- **更多格式与标签保留**：MMP4 / M4A / MP4 可借助 FFmpeg 转 MP3；迁移常用标签、歌词和内嵌封面。
- **更可靠的输出**：同名文件自动编号，转换与校验完成后再提交结果；新增基础校验和可选完整解码校验。
- **界面与诊断**：显示当前阶段和耗时，增加文件详情、客户端兼容性诊断和“打开配置目录”；重复启动会唤起已有窗口。

## 修复内容

- 修复 Windows 配置目录重定向时的 `WinError 17`，配置和任务记录使用实际目录进行安全替换。
- 修复空输出路径误打开工作目录、非法路径触发界面异常，以及保存成功后旧错误提示残留的问题。
- 改善停止、关闭时的资源清理，以及中文 / 空格路径、重复文件和失败输出的处理。
- 无待处理任务时禁用开始按钮，空闲时隐藏进度条，空列表增加拖入提示。

## 使用提示

- 处理加密文件前，先运行兼容的 **32 位 QQ 音乐客户端**。已实测文件版本 **22.5.0.0**；发布程序本身为 Windows 64 位。
- MMP4 / M4A / MP4 转 MP3、完整解码校验需要 FFmpeg，完整 ZIP 包已包含。
- 升级前退出旧版，解压到新文件夹运行；可通过“工具 → 打开配置目录”查看实际配置与任务记录位置。
- “停止处理”在当前文件结束后生效；恢复列表不会自动开始转换。
- 本工具处理已下载的本地文件，不提供下载，也不改变账号的下载权限。
